# Security / Segurança

Report vulnerabilities privately using GitHub private vulnerability reporting if enabled, or contact the maintainer through a private authorized channel. Never put real data or secrets in issues, PRs, logs, CI or reproduction samples. Use synthetic reproductions. No security SLA or certification is claimed.

Supported scope: public/synthetic preview only. Confidential, restricted and unknown classification are blocked by the engine when declared. The engine cannot detect misclassification or guarantee that the host does not transmit information. Do not use real institutional data until independently approved. See docs/THREAT-MODEL.md and docs/INSTITUTIONAL-GATES.md. The owner must enable private vulnerability reporting and maintain a response process before operational adoption.

PT-BR: comunique falhas em canal privado autorizado; não inclua dados reais. Não há garantia de segurança absoluta. A prévia não deve receber dados sigilosos. A TI deve aprovar ambiente, fluxos e controles antes de qualquer piloto com informação institucional.
