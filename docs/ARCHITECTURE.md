# Architecture / Arquitetura

The preview is an offline Python standard-library CLI. Untrusted JSON crosses a bounded parser and strict schema, then deterministic CPM, EVM, risk and RACI functions, then an exclusively published JSON report. The agent, model, filesystem, execution environment and egress remain outside the engine's security boundary. Classification is a declaration; reports and opaque IDs can still be sensitive.

Future modules should expose versioned, explicitly validated contracts, deterministic computations, bounded inputs and traceable assumptions. Keep the core offline; integrations must be opt-in and locally reviewed, with no automatic transmission. Preserve the v1 interface until an intentional compatibility decision.

BR financial integration is a proposal only: project ID mapping must be explicitly authorized and locally protected; currency, reporting period, cash versus earned-value basis, coverage and rejected rows must be reconciled before any comparison. Financial decimal strings and project integer minor units need exact, validated conversion; never sum payroll and expenses blindly or treat budget cash paid as AC without documented basis. No connector, shared database or data transfer is implemented.

Future institutional deployment requires provider-neutral interfaces with institutional identity and SSO/MFA, role authorization, project/department segregation, DLP, encryption, isolated processing, restricted egress, audit trails, retention and disposal policy, and centrally managed versions. These are requirements, not implemented controls. Policy enforcement must occur outside prompts and be tested in the actual environment.
